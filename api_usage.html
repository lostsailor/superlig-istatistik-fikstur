FIFA Dünya Kupası 2026 API

Sahadan.com üzerinden canlı verilerin çekildiği, FIFA 2026 Dünya Kupası için REST API. Tüm endpoint'ler GET metodu ile çalışır ve JSON döndürür.

Base URL

http://localhost:3000

Endpoint'ler

GET/api/all
Tüm veriyi tek seferde döndürür: takımlar, gruplar, maçlar ve stadyumlar.
{
  "teams": [{ "id": "...", "name_tr": "Meksika", "name_en": "Mexico", "flag": "https://flagcdn.com/...", "fifa_code": "MEX", "groups": "A" }],
  "groups": [{ "name": "A", "teams": [...] }],
  "games": [{ "id": "...", "home_team_name_tr": "Meksika", ... }],
  "stadiums": [{ "id": "1", "name_en": "Estadio Azteca", ... }]
}
İpucu: İlk yüklemede tüm veriyi almak için idealdir.

GET/api/games/:grup
Belirtilen gruptaki (A-L) maçları döndürür.
Parametre: A ile L arasında bir grup harfi.
GET /api/games/A

{
  "group": "A",
  "games": [ ... ]
}
  • /api/games/A
  • /api/games/B
  • /api/games/C
GET/api/groups
Tüm grupların puan durumunu döndürür.
{
  "groups": [{
    "name": "A",
    "teams": [{
      "team_id": "...",
      "name_tr": "Meksika",
      "name_en": "Mexico",
      "flag": "https://flagcdn.com/w80/mx.png",
      "fifa_code": "MEX",
      "mp": 1, "w": 1, "d": 0, "l": 0,
      "gf": 2, "ga": 0, "gd": 2, "pts": 3
    }]
  }]
}
GET/api/groups/:grup
Belirtilen grubun puan durumunu döndürür.
  • /api/groups/A
  • /api/groups/D
GET/api/teams
Turnuvadaki tüm takımların listesini döndürür.

Kadro (Lineup) Yapısı

Her oyuncu yalnızca name, number ve position bilgilerini içerir. Tüm name alan türevleri (match_name, first_name, last_name, formation_name) korunur.

{
  "team_A": {
    "formation": "4-3-3",
    "players": [{ "name": "J. Rangel", "match_name": "J. Rangel", "number": "1", "position": ["Goalkeeper"] }],
    "substitutes": [...]
  },
  "team_B": { ... }
}

Olaylar (Events)

Sadece kart olayları döner: YC (sarı kart), Y2 (ikinci sarıdan kırmızı), RC (direkt kırmızı kart). Gol, asist, oyuncu değişikliği vb. olaylar filtrelenmiştir.

{
  "type": "YC",
  "minute": 34,
  "team": "A",
  "player": { "name": "C. Montes", "match_name": "C. Montes", "first_name": "César Jasib", "last_name": "Montes Castro" }
}
